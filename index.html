HOW TO JOIN THE SERVER

Connect on PC, Mobile, or Console using the straightforward steps below.

STEP 1

Launch Minecraft

Open your Minecraft Java client. Versions from 1.8.x to 1.21.x are fully supported (1.20+ recommended for SMP).

STEP 2

Click Multiplayer

From the main menu, click on Multiplayer, then click the Add Server button at the bottom.

STEP 3

Enter Server IP

Server Name: NexCoreMC
Server Address: nexcoremc.in

STEP 4

Connect & Register

Join the server and type /register <password> <confirm password> in chat on your first login.

Open Minecraft PE
